# BlackBull ICT — Website

Premium dark-and-gold landing page for account-management enquiries and VIP membership information.

## Current features
- Responsive single-page design
- Account-management enquiry form that prepares a Telegram message for @BlackBull_Capital
- VIP membership information: Monthly $49, Yearly $149, Lifetime $299
- Risk disclosures and FAQs

## Important limitations
This is a static website. It does not save form submissions, offer an admin dashboard, process payments, or verify VIP access. Card payments and a USDT wallet are not configured. Do not promise guaranteed profits or ask visitors to share MT4/MT5 master passwords.

## Free hosting with GitHub Pages
1. Open the repository Settings → Pages.
2. Under **Build and deployment**, set **Source** to **GitHub Actions**.
3. The workflow in `.github/workflows/pages.yml` will publish the site on the next push.
4. The expected URL is https://mrcaptainfx.github.io/daily-tools/ once deployment succeeds. Check the Pages screen for the confirmed URL and deployment status.

All site files are in the repository root; no build command is needed.
